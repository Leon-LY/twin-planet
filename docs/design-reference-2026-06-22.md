### 关键 UX 模式总结

| 模式 | 说明 |
|------|------|
| 双胞胎切换 | 所有竞品均采用「顶部名字下拉切换」——**无 App 支持同屏双宝对比**（双宝记差异化优势） |
| 单手操作 | 抱娃时单手录入 → 大按钮 + 底部操作区 |
| 暗色模式 | 夜间喂奶不刺眼 → 双宝记已有 |
| 卡片化仪表板 | 喂养/睡眠/尿布一目了然 → 双宝记已有 |
| 微动效 | 柔和过渡不打扰 → 双宝记已有呼吸/反馈/入场三系 |

### CSS 纸质感技术参考
- [freefrontend.com/css-paper-effects](https://freefrontend.com/css-paper-effects/) — 纯 CSS 纸张效果合集
- WXSS 兼容的技术路线（双宝记已在使用）：
  - ✅ `radial-gradient` 多层叠加 → 光斑/纹理
  - ✅ `box-shadow` 多层 → 纸张厚度/内阴影
  - ✅ `border: dashed` → 手撕边/虚线
  - ✅ `transform: rotate` → 胶带/便签倾斜
  - ❌ `filter: blur()` — WXSS 不支持（已修复）
  - ❌ `conic-gradient` / `clip-path` / `mask` — WXSS 不支持

## 六、双宝对比 — 竞品双胞胎模式分析

| 竞品 | 双胞胎支持方式 | 局限 |
|------|:--:|------|
| Huckleberry | 顶部名字下拉切换 | 每次只能看一个宝宝，无同屏对比 |
| Glow Baby | 顶部名字下拉切换 | 同上 |
| Baby Tracker | 设置页切换宝宝 | 切换路径长，无法快速对比 |
| Twiniversity | 主菜单切换模式 | 专为双胞胎设计，但仍分屏非同时 |
| Cradlewise | 右上角宝宝图标切换 | 明确声明「不同时查看两个宝宝」 |

> **双宝记的 `twin-compare` 双宝对比微卡片 + 今日记录分布条形图，在市场上是独一份。**

### 可增强方向

| 当前 | 可增强 |
|------|------|
| 双宝对比条形图（记录次数） | 喂养/睡眠时间轴重叠对比 |
| 同步率百分比 | 「同步时刻」高亮（如同时喂奶） |
| 双宝分别摘要 | 「差异洞察」（如大宝比小宝多睡了 30 分钟） |

## 七、设计参考研究流程（建议）

