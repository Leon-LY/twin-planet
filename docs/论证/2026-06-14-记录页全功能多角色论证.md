## 五、重构方案

### 5.1 交互流重新设计

**核心原则：上下文优先，计时可选。**

#### 喂奶新流程

```
tap "喂奶"
  → 展开上下文面板:
      [左] [右] [🍼瓶喂]
      （如果选瓶喂 → 奶量预设: 60/90/120/150/自定义）
      [开始计时]（次要）  [记录]（主要）
  → 如果"记录": 即时完成，含上下文
  → 如果"开始计时": 启动轻量计时器，显示"喂奶中·左·12分钟"
```

#### 睡觉新流程

```
tap "睡觉"
  → 直接开始计时（逻辑保留）
  → 显示: 宝宝头像 + "在睡觉 💤" + 紧凑计时（不比喂奶大）
  → 停止: "醒了"按钮
```

#### 尿布新流程

```
tap "尿布"
  → 展开微型选择: [💧湿] [💩脏] [💧💩都有]
  → 点击即记录
```

#### 体温新流程

```
tap "体温"
  → 数字选择器: 36.0 ~ 42.0°C (0.1步进)
  → 确认 → 记录: "体温 37.8°C"
```

#### 用药新流程

```
tap "用药"
  → 药名输入 + 剂量输入
  → 确认 → 记录: "布洛芬 2.5ml"
```

### 5.2 UI 重构要点

1. **视觉分离**：计时型（喂奶、睡觉）与即时型（尿布、体温、用药、洗澡）用明确的分隔线 + 标签区分
2. **时钟降级**：计时态中，宝宝身份和喂奶/睡眠上下文是视觉主角；时钟是小而安静的存在
3. **上下文优先**：喂奶的侧别、奶量在选择后立即显示在顶部，不需要滚动
4. **停止按钮语义**："停止记录" → 喂奶"喂完了" / 睡觉"醒了"
5. **最大时长限制**：喂奶 90 分钟自动停止，睡觉 4 小时自动停止
6. **角色差异**：奶奶模式全部即时记录，不触发任何计时器

### 5.3 Store 改动

- `TimerState` 扩展：`medicineName`, `medicineDosage`, `temperatureValue`, `feedingMode`
- `quickLog()` 支持所有上下文字段（diaperType, temperatureValue, medicineName 等）
- 新增 `MAX_TIMER_MINUTES` 常量 + `_checkMaxDuration()` 自动停止逻辑
- `_stopOne()` 移除 1 分钟最小阈值（改为 0 分钟也记录，但标记为"<1分钟"）
