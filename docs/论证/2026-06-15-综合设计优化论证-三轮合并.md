# 双宝手帳 · 综合设计优化论证报告

> 合并两轮论证：手帳设计系统论证（2026-06-15）+ UI交互动效审计论证（2026-06-15）
> 使用 impeccable + design-taste-frontend + css-animations 三技能框架

---

## 一、首次论证：手帳设计元素不足（#1）

**问题**：手帳元素太少、不明显。只有配色和字体，缺少"手工痕迹"。

**五角色共识**：
- 设计师：手帳的灵魂是手工痕迹，不是完美几何
- 宝妈：需要具体的小点缀——胶带、印章、点阵
- 宝爸：结构线（页边、网格）保留，装饰（胶带、贴纸）去掉
- 奶奶：像真的本子，但不要花哨影响阅读
- 技术：WXSS 可行——点阵用 radial-gradient，胶带用 transform:rotate

**实施**：全局手帳CSS系统（11种元素）+ 暗色模式适配

---

## 二、二次论证：UI交互动效审计（#2）

**问题**：动效和交互动画偏离手帳主题，使用通用缓动曲线。

**实施**：手帳动效体系（5条缓动 + 7种关键帧）

---

## 三、三次论证：UI细节打磨（#3·本轮）

**问题**：动画改了很多，但UI基础细节——间距、字号层级、圆角一致性、emoji尺寸——仍然粗糙。

**审计发现**：

| 问题 | 举例 |
|------|------|
| 圆角碎片化 | 6/8/12/14/16/18/20/22/24/28rpx 十种同时存在 |
| 间距不统一 | masthead 44rpx, today-card 36rpx, twins 8rpx |
| 字间距过大 | btn-text letter-spacing:6rpx, jnav-item:3rpx（中文不需） |
| emoji尺寸跳跃 | 16→20→22→24→26→28→30→32→36→40→44→48→56→64→80→120rpx |
| 卡片padding不一 | 28/24, 28/24/24, 28/20/22, 8/16 四种组合 |
| 区域标签单调 | 仅靠字号+颜色区分，无视觉处理 |

**实施**：

### 排版层级规范化
```
Hero:    48rpx (greet-line1)     ← 保持
Title:   36rpx (drawer-title)    ← 保持
Card:    30-32rpx (twin-name)    ← 保持
Body:    26-28rpx                ← 保持
Caption: 22-24rpx                ← 统一提升
Micro:   18-20rpx                ← 统一
```

### 间距节奏统一
```
Section间: 32rpx (masthead/today-card/welcome/twins/sticker/action)
Sub-section: 20rpx (quick-ref/quick-bar/footer)
Card内gap: 16rpx (today-meta/welcome-steps)
```

### 圆角简化
```
Chip/徽章: --radius-sm (12rpx)
卡片/面板: --radius-md (20rpx)  ← 从28rpx降级
全幅按钮: --radius-full (9999rpx)
```

### Letter-spacing 收紧
```
中文按钮: 6rpx→2rpx
导航文字: 3rpx→1rpx
```

## 四、设计Dial设定（贯穿三轮）

| Dial | 值 | 说明 |
|------|:--:|------|
| DESIGN_VARIANCE | 7 | 刻意不对称（旋转卡片、歪斜胶带） |
| MOTION_INTENSITY | 5 | 物理隐喻驱动（盖章、翻页） |
| VISUAL_DENSITY | 3 | 手帳呼吸感（32rpx section间距） |

## 五、已完成改动总览

### 手帳CSS系统（11类）
`journal-paper` `journal-card` `journal-holes` `journal-tape`(4色) `journal-stamp`(3色) `journal-sticky` `journal-curl` `journal-ribbon` `journal-clip` `journal-margin` `journal-tear` `journal-stitch`

### 动效系统（5+7）
5条缓动：`--ease-stamp` `--ease-page` `--ease-peel` `--ease-drop` `--ease-ink`
7种关键帧：`stampDown` `pageFlip` `tapeUnroll` `stickerPlace` `ribbonFall` `cardFloatIn` `inkReveal`

### UI细节打磨
- 14页全量 `journal-paper` + `page-enter`
- 6级 `reveal-*` 交错入场
- 8级 `timeline-enter` 时间线stagger
- `journal-touch` 全局纸页颤动
- Section间距统一32rpx
- Letter-spacing收紧
- 圆角尺度简化
- 暗色模式全局适配
